# 报告生成质量与诊断

每章先按独立职责撰写；前文只传章节目录，不再传大段正文。资料输入按预算取完整片段并去重。模型仍可能产生错误，规则检查不等同于事实核验。

正文检查失败时最多自动修订一次（会额外调用一次模型）。`.env` 中 `REPORT_QUALITY_REPAIR_ATTEMPTS=0` 可关闭，默认值为 `1`。网络或认证失败不自动重试。重新生成全部成功后才替换原报告。

每次章节输出的输入、原文、清理结果和检查结果保存在项目内 `storage/generation_traces`，日志打印对应文件路径。记录含研究资料，应按内部资料保管，不要公开分享整个目录；不记录 API 密钥或 HTTP 请求头。设置 `REPORT_GENERATION_TRACE=0` 可关闭。修改环境配置后重启服务。

代码更新后先在原服务窗口 Ctrl+C 停止，再运行 `.\start.ps1`（局域网使用 `start-lan.cmd`）。重复启动不会自动替换旧进程。离线测试只验证流程与规则，不能保证某个模型真实输出一定通过；真实生成后仍须核对口径、引用和推演依据。
