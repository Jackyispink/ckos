# 阅读版研究内容块：第一阶段

在报告转 PPT 对话框选择“阅读版”，创建新大纲。此模式不调用模型，旧汇报任务不变。

已实现：
- 按原文小节组织内容，短小节合页，保留表格和长句，不按110字筛掉事实。
- 编辑研究问题、判断、正文、限制条件、比较表与至多两张图表。
- 图表自动绑定要求全部来源摘录出现在本内容块；无匹配时不猜测。
- 数据查看显示指标、单位、时间、值和原文出处。没有明确数据口径时显示待确认，不补造。
- 修改保存在 PPT 任务及导出快照，不覆盖原报告；保留版本检查、项目隔离、旧模式兼容。
- 新数字、无引用判断及缺少依据的预测提供人工核对提示，提示不是自动事实核验。

尚未完成的后续阶段：
- 研究内容块成为报告正文生成的主存储，与 Word 共用同一份可编辑数据。
- 从采集阶段直接建立经过校验的数据集，而非从旧报告图表读取数据。
- 行业专用测算模型、情景分析、可编辑产业链关系图。
- 模型按研究问题生成论证内容块与跨章节审稿。

当前阅读版是旧报告的保真适配，不会修正旧报告自身的事实错误、重复论点或口径冲突。
源文缺少比较表时不会擅自把不同年份或口径的公司数字拼成对比表。
