# 制造业独立测算工具

行业研究页面顶部的折叠面板支持有效产能利用率、简化毛利和售价变化情景。所有数据由用户显式输入，程序使用 Decimal 计算，不调用模型、不写入报告或历史版本。

接口：POST `/api/industry/manufacturing/calculate`。输入结构见 `ManufacturingScenario`，包括产品、期间、数量单位、金额单位、来源、有效产能、产量、销量、单位售价、单位变动制造成本、当期固定制造成本和售价变化百分比。

所有数量、成本必须采用一致期间与产品范围。程序不验证来源真实性，不转换单位。固定成本指制造成本，不是期间费用。测算没有模拟存货结转与税费，因此不得将其直接作为财报毛利。售价变化时销量和成本保持不变，属于单因素敏感性而非经营预测。

结果不自动插入 Word/PPT。选择研究项目后可确认口径并保存，通过“读取所选研究的测算”恢复输入。保存接口重新计算结果，拒绝在报告生成时保存。已存在正文的报告在替换测算前自动创建报告快照，恢复历史版本时恢复其测算；旧版本没有测算则恢复为空。没有正文时不创建报告版本备份，因此首次研究的测算仅保留最后一次保存。

保存接口：PUT `/api/industry/projects/{project_id}/manufacturing-scenario`，请求体同试算接口；读取使用同路径 GET。项目删除后其测算随项目删除。输入来源仍需人工审核。

部署后重启服务，并在浏览器按 Ctrl+F5 更新脚本。
