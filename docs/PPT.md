# 行研报告转 PPT

在行业研究中打开已完成报告，点击“生成 PPT”。选择当前报告或历史版本，生成大纲，核对各页标题、要点与图表，然后点击“确认大纲并生成 PPT”。完成后可逐页预览和下载可编辑 PPTX。

## 内容与编辑

- 按摘要与十章组织约 18 页；原文不足时页数可能减少，不凭空补全结论。
- 可增删、排序、取消保留页面，修改标题、要点、来源章节及版式。
- 提供封面、结论、图表、对比、流程、风险六种固定版式。
- 图表来自生成大纲时报告已保存的图表快照。请先在报告看板选好并保存图表；后续报告改动不会自动改变已有 PPT 任务。
- 默认原文提取，不调用模型或搜索。长句可能不进入页面，需人工精简；原章节可在编辑区展开核对。
- AI 提炼是可选项，使用现有模型配置，按章节调用并产生费用。生成后仍需核对数字、口径和预测条件。
- 修改大纲后需要重新生成，避免下载到与修改不一致的文件。任务历史保留独立大纲；需要保留旧 PPT 时，可新建任务或先下载归档。

## 运行与存储

Python 使用 `D:\yidui\miniconda\envs\ckos\python.exe`。
任务、大纲、快照、预览和 PPT 均保存于 `D:\yidui\env\ckos\storage\presentations`。
排版失败可查看对应任务 `render-*\render.log`；已保存大纲不受影响，可以重试。服务重启会中断正在运行的任务，不会自动重复计费调用。

当前渲染器由 JavaScript artifact-tool 驱动，运行路径在 `config/ppt_runtime.json`。此机器已配置本地运行时，但该运行时属于外部安装依赖，并非项目自带可分发依赖。迁移机器或对外部署前必须重新配置可用且许可适用的渲染环境，不能只复制项目就保证可用。

当前实现沿用项目单进程、本机访问模式；不应直接暴露为无鉴权的公网服务。进度显示任务阶段，并非模型或渲染器逐字实时进度。固定版式不等同于人工逐页定制设计，下载前请检查预览。
